# Praxisbeispiele nach Thema

Zu jedem erklärten Konzept nennst du **mindestens ein Praxisbeispiel**: konkret, sichtbar und mit dem Hinweis, *welche* Größe dort entscheidet. Die Liste ist ein Startpunkt; passendere eigene Beispiele sind erwünscht (Maschinenbau, Bau, Fahrzeug, Alltag). Erfinde keine Zahlenwerte als „echte Daten“. Größenordnungen nur als grobe Orientierung und als solche gekennzeichnet.

| Thema | Praxisbeispiel und worauf es ankommt |
|---|---|
| Idealisierungen (starr, Punktmasse, masselos) | Satellitenbahn: Satellit als Punktmasse. Lageregelung desselben Satelliten: starrer Körper mit Trägheitsmoment. Gleiches Objekt, anderes Modell je nach Frage. Seil eines Krans masselos, solange das Seilgewicht ≪ Last. |
| Dimensionsprobe | Formel für eine Durchbiegung kontrollieren: $Fl^3/(EJ)$ ergibt eine Länge. Moment (N·m) und Arbeit (J = N·m): gleiche Dimension, andere Größenart. |
| Kraft als Vektor, Zerlegung | Abschleppseil schräg nach oben: nur die horizontale Komponente zieht, die vertikale entlastet die Vorderachse. |
| actio = reactio, Freischneiden | Rucksack: Gurtkraft auf die Schultern = Gurtkraft auf den Rucksack. Anhängerkupplung: innere Kraft des Gespanns, beim Freischneiden des Anhängers äußere Kraft. |
| Moment, Hebelarm | Radkreuz an der Radmutter, Türklinke (Griff weit vom Scharnier), Drehmomentschlüssel, Schubkarre (Last nah an der Achse). |
| Kräftepaar / freies Moment | Lenkrad mit beiden Händen; Schraubendreher; Antriebsmoment einer Welle. |
| Reduktion, äquivalente Kraftsysteme | Last am Ende eines Kragarms ersetzt durch Kraft + Moment an der Einspannung. So rechnet man Anschlussschrauben. |
| Lager, Bedingungskräfte | Brücke: Festlager auf einer Seite, Loslager (Rollen- oder Gleitlager) auf der anderen, damit die Wärmedehnung keine Zwangskräfte erzeugt. Einspannung: Balkonplatte, Verkehrsschildmast. |
| Zentrales Kraftsystem, Seilkräfte | Straßenlaterne an zwei Seilen, Ampel über der Kreuzung. Flache Seile → riesige Seilkräfte ($\sin(\alpha+\beta)$ im Nenner!). |
| Zwei-/Dreikräftegleichgewicht | Pendelstütze, Hydraulikzylinder am Bagger (Kraft nur in Zylinderachse); Leiter an der Wand (drei Kräfte → gemeinsamer Schnittpunkt). |
| Ebenes Gleichgewicht, Kranausleger | Turmdrehkran, Ladekran am Lkw, Gartentor an zwei Scharnieren (oberes zieht, unteres drückt). |
| Räumliches Gleichgewicht | Kanal- oder Kofferraumdeckel mit Gasdruckfeder, Sonnenschirm mit Seitenwind, Tisch mit drei Beinen. |
| Dyname / Kraftschraube | Bohren und Schrauben: Vorschubkraft plus Drehmoment um dieselbe Achse. |
| Statische Bestimmtheit | Dreibeinhocker wackelt nie (statisch bestimmt), Vierbeintisch wackelt (statisch unbestimmt). Brücken mit Loslager gegen Temperaturzwang. |
| Federn, Serie/parallel | Pkw-Federung (vier Federn parallel); Reifen und Feder in Serie; Ventilfeder mit Vorspannung. |
| Schnittgrößen N, Q, M | Regalbrett mit Büchern (größtes M in der Mitte → bricht dort), Sprungbrett (Kragträger, M maximal an der Einspannung), Brücke unter Lkw-Achslasten. |
| q–Q–M-Zusammenhang | Schneelast auf Dachpfetten (Gleichlast → Parabel im M-Verlauf, $M_{max}=ql^2/8$). |
| Haften, Gleiten | Auto am Hang (Parkbremse, $\tan\varphi\le\mu_h$), Kiste auf dem Lkw (Ladungssicherung), Reifen beim Bremsen (ABS hält im Haftbereich, da $\mu_h>\mu_g$). |
| Kippen vs. Rutschen | Hoher Schrank beim Schieben: zu hoch angreifen → kippt statt rutscht. |
| Selbsthemmung, Schrauben | Schraubzwinge, klemmende Schublade, Wagenheber bleibt oben stehen ($\gamma<\rho_h$), Befestigungsschraube löst sich nicht. |
| Fachwerke | Strommast, Dachstuhl, Kranausleger als Gitter, Eisenbahnbrücke. Nullstäbe sind trotzdem nötig, sie stabilisieren gegen Knicken und andere Lastfälle. |
| Schwerpunkt | Kippstabilität von Lkw und Stapler (Schwerpunkt hoch → kippt früh), Balancieren eines Besens, Gewichtsverteilung im Rennwagen. |
| Teilschwerpunkt mit Ausschnitt | Bauteil mit Bohrungen: Ausschnitt mit negativer Fläche. Leichtbauträger mit Löchern im Steg. |
| Guldinsche Regeln | Volumen eines O-Rings oder Rads (Torus), Blechbedarf für einen Trichter (Kegelstumpfmantel). |
| Massenträgheitsmoment, Steiner | Schwungrad (Masse außen → großes $I$), Eiskunstläuferin zieht Arme an, Handrad mit Kugeln außen. |
| Flächenträgheitsmoment | Lineal hochkant vs. flach biegen ($bh^3/12$: Höhe geht mit der dritten Potenz ein); I-Träger: Material weit weg von der neutralen Faser. |
| Spannung, Hooke, E-Modul | Stahlseil im Aufzug (Dehnung unter Last), Zugversuch im Werkstofflabor. |
| Querkontraktion, ν | Gummiband wird beim Dehnen dünner; Korken ($\nu\approx0$) passt in den Flaschenhals. |
| Wärmedehnung, Zwang | Dehnfugen in Brücken und Schienen; Rohrleitungen mit Kompensatoren. |
| Biegung, Widerstandsmoment | Dimensionierung eines Stahlträgers aus der Profiltabelle über $W_y$; Holzbalken in der Decke. |
| Biegelinie | Durchhang eines Bücherregals, Durchbiegung einer Werkzeugmaschinenspindel (Genauigkeit!), Bauvorschrift zur zulässigen Durchbiegung, z. B. $l/300$ (nur als typische Größenordnung). |
| Statisch unbestimmt | Durchlaufträger über drei Stützen, Lagersenkung erzeugt Zusatzkräfte. |
| Torsion | Antriebswelle im Auto, Bohrer, Torsionsstab-Federung, Schraubendreher. Hohlwelle spart Material bei fast gleichem $J_p$. |
| Offene vs. geschlossene Profile | Längs aufgeschnittenes Rohr ist extrem torsionsweich ($J_T\sim b^3$). |
| Schubspannung durch Querkraft | Kurze, gedrungene Konsolen und Holzbalken mit kleinem $l/h$ (Schubbruch). Bei schlanken Trägern vernachlässigbar ($\tau/\sigma\approx h/4l$). |
| Seile, Kettenlinie | Freileitungen (Durchhang im Sommer größer), Hängebrücke, Seilbahn. Kleiner Durchhang → riesige Horizontalkraft $H=qa$. |
